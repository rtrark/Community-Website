# RTR Community Website deploy notes

## Repo
- Origin: https://github.com/rtrark/Community-Website.git
- Upstream: https://github.com/gameserverapp/Community-Website.git
- Branch: master
- App: Laravel 5.8 community website for GameServerApp.

## Runtime stack
- Debian 11 is the documented target.
- PHP 7.2 FPM with common/mysql/mbstring/xml/curl/gd/zip/bcmath/gmp.
- Composer.
- Node 14.19.0 via nvm.
- npm ci + npm run production.
- Redis server for cache.
- Caddy serving /var/www/public with php_fastcgi to php7.2-fpm.

## Required secrets and inputs
- Domain/subdomain, no protocol, e.g. community.example.com.
- DNS A record to VPS public IP.
- GSA Client ID from https://dash.gameserverapp.com/configure/api.
- GSA Client Secret from same page; never store in chat.
- GSA custom domain + redirect URL approval/config in dashboard.
- GitHub access to rtrark/Community-Website.

## Expected .env keys
- APP_KEY generated by php artisan key:generate.
- GSA_CLIENT_ID.
- GSA_CLIENT_SECRET.
- GSA_REDIRECT_URL=https://DOMAIN/auth/callback.
- CACHE_DRIVER=redis.
- REDIS_HOST=127.0.0.1.

## Server requirements
- New Hetzner VPS; smallest shared vCPU likely enough.
- Ubuntu/Debian acceptable, but Debian 11 safest because installer expects legacy PHP 7.2.
- Public ports: 80/tcp and 443/tcp only.
- SSH should be Tailscale/key-only if possible.
- Backups/snapshots before changes.

## Install flow later
1. Provision VPS.
2. Point DNS A record to VPS IP.
3. Clone rtrark/Community-Website to /var/www.
4. Install PHP 7.2, Composer, Node 14.19.0, Redis, Caddy.
5. Create .env with secret prompt, not chat.
6. composer install --no-interaction --no-dev --prefer-dist.
7. npm ci && npm run production.
8. chown -R www-data:www-data /var/www.
9. Configure Caddy for domain and /var/www/public.
10. Reload Caddy, verify HTTPS.
11. Smoke test pages, auth callback, shop, API calls.

## Current improvements in our fork
- `shop_pack` pagebuilder blocks cache individual shop item API responses for 10 minutes by default.
- Tune with `SHOP_PACK_CACHE_TTL` in `.env`.
- Official installer now clones `rtrark/Community-Website` instead of upstream.
- Docker dev stack added; web binds `127.0.0.1:8080` only for safe parallel testing.
- Node-sass 4 + Node version is brittle; pin Node 14.19.0.
- Installer writes /etc/fstab, /etc/sysctl.conf, /etc/caddy/Caddyfile and /var/www.
- No DB migrations found in initial quick scan; app mostly consumes GSA APIs and cache.
